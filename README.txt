WATERWISE - FINAL PROJECT

PROJECT:
Water Consumption Prediction & Analytics

TECHNOLOGIES:
HTML, CSS, Bootstrap, JavaScript, PHP, MySQL, Python, Pandas,
NumPy, Scikit-learn, Matplotlib, Seaborn, Random Forest Regression.

FINAL MODULES:
1. Dashboard
2. Prediction
3. History
4. Analytics

Clustering and Association have been removed.

DATABASE:
The project uses the existing water_consumption database with:
- users
- consumption
- predictions

IMPORTANT:
Do NOT delete your existing database if it is already created.

SETUP:

1. Put this folder inside:
   D:\xampp\htdocs\

2. Final location:
   D:\xampp\htdocs\WaterConsumptionProject

3. Start Apache in XAMPP.

4. Make sure MySQL80 is running.

5. Open config\db.php and replace:
   YOUR_MYSQL_PASSWORD
   with your actual MySQL root password.

6. Install Python packages:
   pip install -r requirements.txt

7. Open VS Code terminal in:
   D:\xampp\htdocs\WaterConsumptionProject\python

8. Run these commands in order:

   python generate_dataset.py
   python preprocessing.py
   python classification.py
   python train_model.py
   python visualization.py

9. Test prediction:

   python predict.py 4 2 4 4 2 1 2

10. Open:

   http://localhost/WaterConsumptionProject/

11. Test:
   Register
   Login
   Dashboard
   Prediction
   Consumption
   History
   Analytics

ML LOGIC:
The model predicts total household water consumption in litres/day.

Inputs:
- family_members
- bathrooms
- bathing_freq (events/day)
- laundry_freq (cycles/week)
- dishwashing (events/day)
- garden (Yes/No)
- vehicle_wash (washes/week)

Target:
- consumption (litres/day)

The training dataset is synthetic and generated by Python.
User-entered actual consumption is stored in MySQL for history
and personal analytics. It does not automatically retrain the model.
